# Aplikasi Profil Mahasiswa Flutter

Aplikasi Profil Mahasiswa merupakan proyek Ujian Tengah Semester (UTS) mata kuliah Pemrograman Mobile yang dibuat menggunakan Flutter dan bahasa pemrograman Dart.

## 2. Fitur Aplikasi
1. **Profil:** Menampilkan foto, nama, bio, email, nomor telepon, dan alamat.
2. **Edit Profil:** Mengubah dan menyimpan informasi mahasiswa.
3. **Tentang Aplikasi:** Menampilkan informasi aplikasi, versi, dan pembuat.
4. **Dark Mode & Light Mode:** Mengubah tema tampilan.
5. **Navigasi:** Berpindah halaman menggunakan Navigator.
